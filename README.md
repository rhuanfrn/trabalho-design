---SISTEMA DE ESTOQUE EM C---

DESCRIÇÃO DO PROGRAMA:
O programa consiste em um Sistema de Gerenciamento de Estoque desenvolvido em linguagem C, com o objetivo de facilitar o cadastro, a consulta e o controle de produtos. O sistema permite cadastrar produtos informando nome, preço e quantidade, consultar os produtos cadastrados, pesquisar itens pelo nome e realizar entradas e saídas de mercadorias, atualizando automaticamente as quantidades disponíveis. O programa possui um menu interativo que permite ao usuário escolher as operações desejadas e encerrar o sistema quando necessário.

DESCRIÇÃO DO FUNCIONAMENTO DO CODIGO:
O funcionamento do programa começa com a exibição de um menu principal, no qual o usuário pode escolher entre cadastrar produtos, consultar produtos, alterar o estoque ou encerrar o sistema. Após selecionar uma opção, o programa utiliza a estrutura `switch/case` para identificar a escolha e executar a operação correspondente. No cadastro, são informados o nome, o preço e a quantidade do produto. Na consulta, é possível visualizar todos os produtos cadastrados ou pesquisar um item específico pelo nome. Na alteração de estoque, o usuário pode adicionar ou retirar unidades, respeitando a quantidade disponível. Esse processo se repete até que o usuário escolha a opção de sair, encerrando a execução do programa.
