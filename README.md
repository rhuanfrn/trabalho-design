---SISTEMA DE ESTOQUE EM C---

DESCRIÇÃO DO PROGRAMA:
O programa consiste em um Sistema de Gerenciamento de Estoque desenvolvido em linguagem C, com o objetivo de facilitar o cadastro, a consulta e o controle de produtos. O sistema permite cadastrar produtos informando nome, preço e quantidade, consultar os produtos cadastrados, pesquisar itens pelo nome e realizar entradas e saídas de mercadorias, atualizando automaticamente as quantidades disponíveis. O programa possui um menu interativo que permite ao usuário escolher as operações desejadas e encerrar o sistema quando necessário.
